# 03 — MazOS: Build-in-Public Personal Brand (the Hub)

**Goal:** grow the audience and credibility of **Manazir "Maz" Hussain** as an applied-AI /
agent engineer who ships real products solo — attracting roles, contracts, partnerships, and
a following that becomes distribution for every product (JobFilter, Agent Nudge, and next).

**Why this is the hub:** MazOS isn't a product marketing plan — it's the *operator* behind
all of them. Growing this brand compounds the others (see README flywheel). It is the highest-
leverage of the three because the audience it builds is reusable for every future launch.

**Product truth (from repos):** `mazos-site` = the portfolio / candidate identity (open to
roles/contracts/partnerships; current issues #2/#3 focus on truth-aligning and proving it).
`mazos-ui` / MAZos = an early operator console for supervising agent runs. Brand voice:
professional, technically specific, transparent about limitations.

---

## 1. Positioning

**UVP (not a job title):**
> *"I ship production products end-to-end, solo, by orchestrating AI agents. Here's the live
> app, the open-source code, and the receipts."*

- **Proof already exists:** JobFilter (live, revenue path), Agent Nudge (OSS dev tool),
  Scrap Finance Partners, OpenFlowKit, and more — a portfolio of *shipped* work, not demos.
- **Rare angle:** most "AI engineers" post prompts and threads; few can point to multiple
  live, tested, honestly-scoped products built solo with agents. That gap is the whole brand.
- **Audience segments:** (1) hiring managers / clients (roles + contracts), (2) the AI-eng /
  build-in-public community (followers + distribution), (3) potential collaborators/partners.

---

## 2. Foundations first (finish before amplifying)

Issues #2 (truth-align portfolio) and #3 (candidate identity + external proof) are correctly
prioritised — **do not amplify a brand that isn't buttoned up.** Complete:
1. **Portfolio hardening** (`mazos-site`): each project with status, live link, code link,
   honest limitations, and a one-line "what I actually did." Truthful = differentiated.
2. **External proof:** GitHub profile README as a mini-portfolio; consistent name/handle
   across LinkedIn, X, GitHub; a short "about" that states the UVP in one breath.
3. **Contact/conversion paths:** the three-route contact (hire / commission / collaborate)
   should be frictionless and tracked.
4. **Portfolio SEO:** rank for `Manazir Hussain`, `Maz Hussain applied AI engineer`, and
   `agent engineer UK`. Clean metadata, fast static export (already the stack).

---

## 3. Channels (ranked by goal)

1. **LinkedIn (primary for roles/contracts):** where hiring managers and clients are. Post
   shipping logs, technical lessons, and opinion in a credible, no-hype voice. Personal
   branding here takes ~90 days to show traction — commit to the cadence.
2. **X/Twitter (primary for community + build-in-public):** where the AI-eng crowd lives and
   where Agent Nudge's audience overlaps. Threads, demo clips, hot takes on agent engineering.
3. **GitHub profile (proof surface):** pinned repos, profile README, green graph. Devs and
   technical hiring managers check this before they believe anything.
4. **Owned writing (blog/newsletter):** the durable asset — long-form build logs and
   teardowns that you *own* and that feed both LinkedIn and X. Consider a simple newsletter.
5. **YouTube (optional, later):** "how I built and shipped X solo with agents" walkthroughs;
   high-effort but high-credibility and evergreen.

---

## 4. Content engine

**Five core topics** (pick and stay consistent — per the research, 3–5 topics beat random):
1. **Shipping logs** — what I built this week across JobFilter / Agent Nudge / next, with
   receipts (commits, live links, screenshots).
2. **Agent-orchestration craft** — how I actually run multiple agents to ship solo (this is
   the signature topic; it's also Agent Nudge's problem space — synergy).
3. **Build teardowns** — a real technical decision, honestly explained (the same teardown
   muscle used in JobFilter and Agent Nudge content).
4. **Lessons / opinions** — what solo + agents changes about product engineering; contrarian,
   experience-backed takes.
5. **Career/behind-the-scenes** — the "open to roles/contracts" narrative, made concrete.

**Engagement > broadcast:** per the research, consistent in-industry commenting compounds
faster than chasing viral posts. Budget daily time for genuine replies in the AI-eng
conversation, not just posting.

**Repurposing rule:** one build log per week → LinkedIn post + X thread + newsletter section
+ (optional) short clip. Write once, distribute four ways.

---

## 5. The halo strategy (how MazOS pulls the products)

- Every JobFilter or Agent Nudge milestone becomes a **first-person build log** on Maz's
  channels → the personal audience becomes each product's launch distribution.
- Each product's traction becomes **proof** in the portfolio and the next pitch/post.
- Agent Nudge's topic (multi-agent coordination) *is* Maz's signature topic (orchestrating
  agents to ship solo) — the personal brand and the product reinforce the exact same story.
- Net: the more Maz ships and narrates, the cheaper every future launch's distribution gets.

---

## 6. 90-day plan

**Month 1 — Foundation**
- Close issues #2/#3: portfolio truth-aligned, candidate identity + external proof complete.
- Lock consistent handle/bio/UVP across LinkedIn, X, GitHub. Ship GitHub profile README.
- Start posting: 3×/week LinkedIn, daily-ish X presence (1 post + genuine replies).
- Publish first 2 build logs (one JobFilter, one Agent Nudge) as the flagship format.

**Month 2 — Cadence + first spike**
- Sustain cadence; launch the newsletter (owned asset) with the build-log backlog.
- Ride Agent Nudge's launch week (see `02`) as Maz's biggest build-in-public moment.
- Start one longer teardown/opinion piece that can travel (dev.to / LinkedIn article).

**Month 3 — Compound + inbound**
- Double down on the 2 formats that pulled best; track inbound (recruiters, clients, collabs).
- First "how I ship solo with agents" long-form (blog or video).
- Review follower growth, profile views, and inbound quality; set Q2 targets.

## 7. KPIs

| Metric | Why | 90-day target (starter) |
| --- | --- | --- |
| LinkedIn followers + profile views | Roles/contracts reach | steady compounding; traction by day 90 |
| X followers + engaged replies | Community + distribution | growing engaged base |
| Newsletter subscribers | Owned, reusable audience | list live, first cohort |
| Inbound (recruiters/clients/collabs) | The actual business goal | first qualified inbound |
| Portfolio sessions + name-search rankings | Proof discoverability | page-1 for own name + "applied AI engineer UK" |

## 8. Guardrails / do-not
- Keep the honest/evidence voice — no hype, no inflated claims (matches issues #2/#3).
- Don't fragment identity across mismatched handles/bios — consistency is credibility.
- Don't broadcast without engaging — the compounding is in the replies.
- Don't let posting cannibalise shipping — the *shipping* is what makes the content real.
